발송 명단 추출 앱

보낼 대상을 문장으로 적으면 AI가 조회문을 써 준다. 실행 버튼과 발송은 사람이 누르고, 고객 명단은 AI에게 가지 않는다.

만든 때
2026년 6월
지금
업무에서 사용 중
쓰는 사람
안내 문자를 보내는 담당자
  • 0AI에게 보내는 고객 명단
  • 16고를 수 있는 데이터 표
  • 195자동 테스트

왜 필요했나

고객에게 안내 문자를 한 번 보내려면 대상자 명단이 필요하다. 조건에 맞는 사람을 뽑고, 이미 받았거나 받지 않겠다고 한 사람을 빼고, 번호를 정리한다.

보낼 때마다 같은 일을 하는데 조건만 매번 달랐다. 그리고 조건을 데이터베이스 조회문으로 옮기는 일은 그 문법을 아는 사람만 할 수 있었다.

구조 한눈에

단계별로 보면

  1. 1

    사람요청을 문장으로

    보낼 대상을 평소 말하듯 적는다. 예를 들면 "지난달 상담한 보호자 중 아직 이용하지 않은 분". 문장 없이 칸을 직접 채워도 된다.

  2. 2

    프로그램조건 칸으로 나눈다

    앱이 이 문장만 AI 모델에게 보내 대상 표(상담 기록·이용자 정보처럼 주제별로 나뉜 데이터 묶음 16개 중 하나)·기간·조건·제외 대상 칸으로 나눠 받는다. 모르는 표나 잘못된 날짜는 버리고 그 이유를 화면에 적는다.

  3. 3

    사람조건을 확인·고친다

    AI가 조건을 다르게 알아들어도 명단은 그럴듯하게 나온다. 그래서 사람이 나뉜 칸을 보고 고치는 것이 첫 번째 확인 지점이다.

  4. 4

    프로그램조회문을 받아 검사

    확인한 조건과 표 정보만 AI에게 보내 조회문을 받는다. 앱은 그 문장이 데이터를 읽기만 하는지 코드로 검사하고, 고치거나 지우는 문장이면 막는다.

  5. 5

    사람실행 버튼을 누른다

    사람이 실행을 누르면 앱이 사내 데이터 조회 도구로 조회한다. 보내기 직전에 한 번 더 검사하고, 결과는 앱이 켜져 있는 동안 화면에만 띄우고 파일로 저장하지 않는다(앱을 끄면 사라진다). 조회 도구가 한 번에 돌려주는 줄 수에는 한도가 있어서, 결과가 다 오지 않았으면 빨간 경고를 띄운다(모르고 보내면 대상이 빠진다).

  6. 6

    프로그램제외·중복 빼고 엑셀로

    팀 공용 시트의 발송 제외 명단을 빼고, 같은 번호를 하나로 줄여 엑셀로 만든다. 누가 왜 빠졌는지도 따로 적는다. 제외 명단을 못 읽으면 아무것도 만들지 않고 멈춘다.

  7. 7

    사람발송은 사람이 직접

    엑셀을 문자 발송 서비스에 올리고 보내는 것은 사람이 한다. 앱에는 발송 기능이 없다.

쉽게 말하면

조회문(SQL)
데이터베이스에 "이런 조건의 사람을 찾아 줘"라고 보내는 문장. 정해진 문법이 있어 배운 사람만 쓸 수 있었다.
읽기 전용 검사
AI가 쓴 조회문이 데이터를 보기만 하는지 앱이 먼저 확인하는 것. 고치거나 지우는 문장이면 실행 자체를 막는다.
사내 데이터 조회 도구
회사 데이터베이스를 조회하는 사내 웹 도구. 앱은 이 도구를 거쳐서만 데이터를 읽는다.
제외 명단
다시 연락하면 안 되는 사람들의 번호 목록(수신 거부 등). 팀이 공용 시트로 관리한다.

사람이 하는 일

  • 보낼 대상을 문장으로 적는다
  • AI가 나눈 조건을 확인하고 고친다
  • 실행 버튼을 누른다
  • 엑셀을 문자 서비스에 올려 보낸다

프로그램·AI가 하는 일

  • 문장을 조건 칸으로 나눈다 (AI)
  • 조건으로 조회문을 쓴다 (AI)
  • 조회문이 읽기만 하는지 검사한다 (프로그램)
  • 제외 명단·중복을 빼고 엑셀을 만든다 (프로그램)

지키는 선

이 도구가 일부러 하지 않는 것들입니다.

  • 고객 명단은 AI에게 보내지 않는다. AI가 받는 것은 사람이 쓴 문장과 조건, 표의 구조뿐이다.
  • 조회 결과는 화면에만 띄우고 파일로 저장하지 않는다.
  • 제외 명단을 못 읽으면 멈춘다. 조용히 넘어가면 받으면 안 되는 사람이 받는다.
  • 발송 기능은 넣지 않았다. 잘못 뽑힌 명단이 그대로 발송으로 이어지면 되돌릴 수 없다.
