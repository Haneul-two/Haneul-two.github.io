상담 품질 카드 스킬

상담 통화를 글로 옮긴 기록을 붙여 넣으면 공식 평가 기준에 맞춘 코칭 카드 1건을 쓴다. 판단 기준은 AI가 만들지 않고, 사람이 쓴 문서를 매번 펴서 본다.

만든 때
2026년 7월
지금
상담 품질 점검에 사용 중
쓰는 사람
상담 품질 점검 담당자
  • 6답지로 쓴 실제 카드
  • 17자동 채점 항목
  • 750~2,500카드 본문 글자 수

왜 필요했나

상담 품질을 보는 팀은 통화를 듣고, 보완할 점이 있던 상담을 카드로 남긴다. 어떤 기준을 어겼고 어떻게 했어야 했는지를 적는 일이다.

판단 기준은 이미 상담 매뉴얼과 평가 기준표로 있었다. 그런데 매번 다시 읽고 적용해 한 건씩 쓰는 데 오래 걸렸고, 건수는 쌓였다.

구조 한눈에

단계별로 보면

  1. 1

    사람기록을 붙여 넣는다

    점검 담당자가 통화를 글로 옮긴 전사문과 그 통화의 고유번호를 붙여 넣는다. 고유번호가 없으면 시작하지 않고 먼저 묻는다.

  2. 2

    프로그램번호·메일 가림

    프로그램이 전화번호·주민번호·카드번호·이메일을 먼저 가린다. AI의 성실함에 맡기지 않고 코드가 한다.

  3. 3

    AI어긋난 곳을 찾는다

    AI가 상담 매뉴얼을 펴서 통화에서 기준과 어긋난 지점을 찾고, 처음 문의한 신규 고객, 이미 이용 중인 기존 고객, 그만두려는 이탈 고객 중 어떤 통화인지 가른다.

  4. 4

    AI평가 항목으로 분류

    찾은 문제를 평가 기준표의 공식 항목 이름으로 바꾸고, 같은 문제는 하나로 합친다. 새 기준을 만들지 않는다.

  5. 5

    AI카드 1건 작성

    통화 정보, 요약, 평가 항목, 상세 피드백, 개선 제안, 종합 의견 순서로 된 양식에 맞춰 카드를 쓴다. 본문은 750~2,500자이고, 고객 이름은 성만 남기고 가린다(김○○). 팀원이 실제로 쓴 카드가 분량의 위·아래 기준이다. 결과는 내 컴퓨터 폴더에만 저장한다.

  6. 6

    사람읽고 판정해 올린다

    사람이 읽고 맞는지 판정한 뒤 직접 팀 문서에 붙인다. 목소리로만 알 수 있는 것은 "음성 확인 필요"로 따로 빼 두므로 사람이 듣고 정한다.

쉽게 말하면

스킬
AI에게 미리 써 둔 업무 매뉴얼. "이런 요청이 오면 이 문서를 이 순서로 펴서 해"를 파일로 적어 둔 것.
전사문
통화 녹음을 글로 옮긴 것.
마스킹
전화번호·이름 같은 개인정보를 ○○처럼 가리는 것.
답지(골든 세트)
팀원이 실제로 쓴 카드 6건. AI가 쓴 카드가 이것과 얼마나 다른지 숫자로 잰다. 처음엔 AI 카드가 2~8배 길었다.

사람이 하는 일

  • 전사문과 고유번호를 붙여 넣는다
  • 카드를 읽고 맞는지 판정한다
  • 음성 확인이 필요한 부분을 듣는다
  • 팀 문서에 직접 올린다

프로그램·AI가 하는 일

  • 전화·주민·카드 번호와 메일을 가린다 (프로그램)
  • 매뉴얼·기준표로 판단하고 분류한다 (AI)
  • 양식대로 카드를 쓴다 (AI)
  • 스킬을 고칠 때마다 결과 카드를 분량·양식 등 17개 항목으로 자동 검사해, 전보다 나빠진 곳을 찾는다 (프로그램)

지키는 선

이 도구가 일부러 하지 않는 것들입니다.

  • 판단 기준을 AI가 새로 만들지 않는다. 매번 사람이 쓴 매뉴얼과 기준표를 펴서 본다.
  • 카드와 전사문을 공개 게시하지 않는다. 저장은 내 컴퓨터 폴더, 게시는 사람이 팀 문서에만 한다.
  • 전사문에 없는 날짜·이름은 지어내지 않고 "(추후 입력)"으로 비운다.
  • 목소리로만 알 수 있는 지적은 본문에 단정해 쓰지 않는다.
