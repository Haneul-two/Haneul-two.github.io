만족도 조사 발송 자동화

하루치 상담 이력 파일을 올리면 만족도 조사 문자를 보낼 목록을 만든다. 애매한 건은 사람이 고르고, 전송 버튼은 사람이 누른다.

만든 때
2026년 5월
지금
팀 공용 웹 화면으로 사용 중
쓰는 사람
상담팀 담당자
  • 3갈래로 나누는 규칙
  • 4읽어 오는 시트 탭
  • 0자동 전송

왜 필요했나

상담을 받은 고객에게 상담이 어땠는지 묻는 문자를 보낸다. 그런데 하루치 상담 이력에는 부재·무응답, 이미 받은 사람, 받지 않겠다고 한 사람이 섞여 있다.

이걸 손으로 거르면 매번 같은 규칙을 다시 적용해야 했고, 놓치면 같은 사람이 또 받거나 받으면 안 되는 사람이 받았다.

구조 한눈에

단계별로 보면

  1. 1

    사람상담 이력 파일 올리기

    상담 프로그램에서 내려받은 하루치 상담 이력 엑셀을 웹 화면에 올린다. 원본 파일은 고치지 않는다.

  2. 2

    프로그램시트에서 명단 읽기

    처리를 시작하면 구글 시트에서 최근 한 달 발송 기록, 상담사별 조사 링크(고객은 자기를 상담한 상담사의 조사 링크를 받는다), 만족도 조사 제외 고객, 팀 공용 발송 제외 명단을 읽어 온다.

  3. 3

    프로그램규칙으로 세 갈래

    부재·무응답, 제외 명단, 같은 파일 안 중복 번호, 최근 한 달 안에 보낸 번호는 삭제. 회사 서비스와 관계없는 문의로 분류된 상담, 다른 연락처 칸에 번호가 있는 건, 휴대전화가 아닌 번호는 확인 필요. 나머지는 발송 대상.

  4. 4

    사람확인 필요 건 고르기

    확인 필요 건만 표로 보고 넣을지 체크한다. 다른 연락처로 보내야 하는 건은 그 번호를 쓰도록 고른다.

  5. 5

    프로그램업로드 파일 만들기

    문자 서비스에 올릴 엑셀과 함께 발송 목록, 확인 목록, 삭제 목록(사유 포함), 건수 요약을 만든다. 확인·삭제 목록은 번호를 가린다.

  6. 6

    사람문자 서비스에서 전송

    사람이 문자 서비스에 엑셀을 올려 직접 전송한다. 최종 전송 버튼은 자동화하지 않았다.

  7. 7

    사람발송 기록 반영

    발송 기록 탭은 날짜별 묶음으로 최근 한 달 치만 둔다. 보낸 엑셀을 다시 올리면 가장 오래된 날 묶음을 지우고 오늘치를 넣을 계획을 보여 준다. 사람이 "시트에 반영"을 눌러야 쓴다. 이 기록이 다음 발송의 중복 방지 기준이 된다.

쉽게 말하면

만족도 조사 문자
상담을 받은 고객에게 상담이 어땠는지 묻는 링크를 보내는 문자.
구글 시트
여러 사람이 함께 고치는 온라인 표. 발송 기록과 제외 명단을 여기서 관리한다.
제외 명단
다시 연락하면 안 되는 사람들의 번호 목록. 만족도 조사 전용 명단과 팀 공용 명단 두 가지를 모두 읽는다.
마스킹
전화번호 같은 개인정보를 일부 가려서 보여 주는 것.

사람이 하는 일

  • 상담 이력 파일을 올린다
  • 확인 필요 건을 보고 넣을지 고른다
  • 문자 서비스에서 직접 전송한다
  • 발송 기록 반영 버튼을 누른다

프로그램·AI가 하는 일

  • 시트에서 발송 기록·링크·제외 명단을 읽는다
  • 규칙으로 세 갈래로 나눈다
  • 업로드 파일과 사유 목록을 만든다
  • 발송 기록 탭에서 오래된 날을 지우고 오늘치를 넣는다

지키는 선

이 도구가 일부러 하지 않는 것들입니다.

  • 원본 상담 이력 파일은 고치지 않는다.
  • 최종 전송 버튼은 자동화하지 않는다. 사람이 문자 서비스에서 누른다.
  • 확인·삭제 목록에는 번호를 가려서 쓴다.
  • 계정과 비밀번호는 코드나 파일에 저장하지 않는다.
